# StringOpsStatic

## Пространство имён
Все функции библиотеки реализованы в пространстве имён `StringOps`
для предотвращения конфликтов имён.

## Разрешение конфликта слияния

Для практики работы с конфликтами слияния были выполнены следующие шаги:

1. В ветке `change-rotate` была изменена реализация функции `rotateString`.
2. В ветке `add-reverse` была добавлена новая функция `reverseString`.
3. При слиянии веток возник конфликт в файле `StringOps.cpp`.
4. Конфликт был разрешён вручную путём сохранения обеих реализаций.
5. После разрешения конфликта изменения были успешно зафиксированы.
