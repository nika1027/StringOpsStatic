# StringOpsStatic

## Описание
Проект представляет собой статическую библиотеку для обработки строк на языке C++.
Библиотека содержит набор функций для работы со строками и используется в других проектах.

## Пространство имён
Все функции библиотеки реализованы в пространстве имён `StringOps`,
что позволяет избежать конфликтов имён и улучшает структурированность кода.

## Разрешение конфликтов слияния
В рамках выполнения лабораторной работы была проведена практика работы с конфликтами слияния в системе контроля версий Git.

Процесс включал следующие этапы:
- в одной ветке была изменена реализация существующей функции библиотеки;
- в другой ветке была добавлена новая функция;
- при попытке объединения веток возник конфликт слияния в исходном файле библиотеки;
- конфликт был разрешён вручную путём анализа изменений и объединения корректной логики;
- после разрешения конфликта был создан коммит слияния и изменения успешно зафиксированы в репозитории.

Данный процесс продемонстрировал навыки работы с ветками и разрешения конфликтов в Git.
